# Open-source project policies

A collection of reports on how open-source projects set expectations for
contributions and other project work. Each report links to the project's own
policy wording.

## Browse the reports

- [Project list](reports/chaoss_list_of_projects/README.md)
- [Critical dependencies](reports/critical-dependencies/README.md)

## What the reports cover

Reports summarize policy guidance for contributions, meeting tools, content,
moderation, review, use of automated tools, environmental impact, project
infrastructure, and handling of project data.

The tables show whether a policy addresses each topic and how much detail it
provides. Quotes and links in the reports let readers check the original
wording. The summaries describe what a policy says; they do not rate whether
it is good or bad.
