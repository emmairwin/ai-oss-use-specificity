[^fn1]: “the GNU Compiler Collection (GCC) policy is to decline any legally significant contributions which include LLM-generated content or are derived from LLM-generated content.” [https://gcc.gnu.org/ai-policy.html](https://gcc.gnu.org/ai-policy.html)

[^fn3]: contributor
[^fn4]: “patch review (supporting human review, not replacing it) and debugging, so long as the output is not included in the contributions to the project.” [https://gcc.gnu.org/ai-policy.html](https://gcc.gnu.org/ai-policy.html)
[^fn5]: Applies to a contributor's personal use of AI for patch review, so long as the AI output is not itself included in the contribution submitted to the project.
[^fn6]: “An LLM may not commit code to the project repository.” [https://gcc.gnu.org/ai-policy.html](https://gcc.gnu.org/ai-policy.html)
[^fn7]: An LLM may not commit code to the repository; contribution submission and inclusion decisions must be made by a human.
