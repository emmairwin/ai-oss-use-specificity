`X` addressed · `~` partial · `R` raised in the policy's rationale but not governed · blank not mentioned. Footnotes carry the policy's own words and a link to the line they came from.

[^fn1]: “Comments that are originally created by an LLM posted from a personal user account.” [https://forge.rust-lang.org/policies/llm-usage.html](https://forge.rust-lang.org/policies/llm-usage.html)
[^fn2]: LLM-created code changes only allowed under the 'experiment' when pre-arranged with a reviewer, non-critical (no soundness impact), well-tested, well-reviewed, and tagged 'llm-assisted'; circuit breaker disallows new LLM-created PR merges if >50% of PRs in a 6-week window were LLM-created, cooldown 10 days; comments/issue bodies/PR descriptions originally created by an LLM are banned; trivial changes, translations, bug-discovery allowed with disclosure.
[^fn3]: contributor
[^fn4]: “Documentation that is originally created by an LLM.” [https://forge.rust-lang.org/policies/llm-usage.html](https://forge.rust-lang.org/policies/llm-usage.html)
[^fn5]: Documentation originally created by an LLM is banned, including non-trivial source comments (doc-comments, safety comments, multi-paragraph non-doc comments) and compiler diagnostic messages; trivial changes are excepted.
[^fn6]: contributor
[^fn7]: “Violations will first result in a warning, and repeated violations may result in a ban.” [https://forge.rust-lang.org/policies/llm-usage.html](https://forge.rust-lang.org/policies/llm-usage.html)
[^fn8]: “Treating an LLM review as a sufficient condition to merge or reject a change.” [https://forge.rust-lang.org/policies/llm-usage.html](https://forge.rust-lang.org/policies/llm-usage.html)
[^fn9]: LLM 'review bot' accounts require one-time maintainer approval, must be clearly marked as an LLM on a separate account, must be blockable, and their comments must be non-blocking; LLM reviews (bot or private) cannot substitute for human review or self-review; private personal-use review does not require disclosure, public review-bot use requires disclosure.
[^fn10]: reviewer
[^fn11]: “Policies or processes that are written such that an LLM is required to execute them.” [https://forge.rust-lang.org/policies/llm-usage.html](https://forge.rust-lang.org/policies/llm-usage.html)
[^fn12]: Policies or processes written such that an LLM is required to execute them are banned; documentation must be authored for humans primarily, with LLM documentation (e.g. AGENTS.md-style instructions) only permitted to summarize, not add new detail.
[^fn13]: given as a reason for another rule: “many others feel that its negative impact on society and the climate are severe enough that no use is acceptable”
