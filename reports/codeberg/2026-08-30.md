# AI policy coverage: codeberg

Source: <https://blog.codeberg.org/protecting-our-floss-commons-from-llms.html>

| Domain | Addressed | Lean | Supervision | Scope | Accountability | Proportionality |
|---|:-:|---|---|:-:|:-:|:-:|
| Code contributions | ~[^fn1] | restrictive |  | X[^fn2] |  |  |
| Notetaker and meeting bots |  |  |  |  |  |  |
| Content and documentation |  |  |  |  |  |  |
| Moderation and enforcement | ~[^fn3] |  | `human_in_the_loop` | X[^fn4] |  |  |
| Review of contributions |  |  |  |  |  |  |
| Autonomous and agentic use | ~[^fn5] |  | `banned` |  |  |  |
| Environmental impact | R[^fn6] | restrictive |  |  |  |  |
| Infrastructure strain | ~[^fn7] | restrictive |  | X[^fn8] |  | X[^fn9] |
| Data use for training | X[^fn10] |  | `banned` | X[^fn11] | X[^fn12] |  |

`X` addressed · `~` partial · `R` raised in the policy's rationale but not governed · blank not mentioned. Footnotes carry the policy's own words and a link to the line they came from.

[^fn1]: “Projects written and maintained with heavy use of LLMs” [https://blog.codeberg.org/protecting-our-floss-commons-from-llms.html](https://blog.codeberg.org/protecting-our-floss-commons-from-llms.html)
[^fn2]: Discourages 'heavy use of LLMs' in writing/maintaining projects; tolerates LLM contributions accepted unknowingly/willingly if the project does not otherwise involve heavy LLM use; tolerates side projects using 'very few resources'.
[^fn3]: “Our moderation team will not start off generating an exhaustive list of affected repositories to remove.” [https://blog.codeberg.org/protecting-our-floss-commons-from-llms.html](https://blog.codeberg.org/protecting-our-floss-commons-from-llms.html)
[^fn4]: No mass-deletion; no automated scanning of content; cases handled individually as they arise.
[^fn5]: “Projects that are created by LLM "agents" in autonomous ways” [https://blog.codeberg.org/protecting-our-floss-commons-from-llms.html](https://blog.codeberg.org/protecting-our-floss-commons-from-llms.html)
[^fn6]: given as a reason for another rule: “Due to the energy and water demands that are inherent to the data centers built specifically for training LLMs, many communities already today experience rising consumer costs for both electricity and drinking water.”
[^fn7]: “Projects where the amount of resources (e.g. storage, CI/CD) is significantly larger than what the involved amount of people could have created by hand” [https://blog.codeberg.org/protecting-our-floss-commons-from-llms.html](https://blog.codeberg.org/protecting-our-floss-commons-from-llms.html)
[^fn8]: Projects consuming resources (storage, CI/CD) 'significantly larger than what the involved amount of people could have created by hand' may no longer be welcome; side projects using 'very few resources' are tolerated.
[^fn9]: Resource use disproportionate to community/contributor size ('significantly larger than what the involved amount of people could have created by hand') vs. 'very few resources' tolerated threshold
[^fn10]: “The Codeberg forge and its associated services are not and will not use the code or data of projects and users to train "Artificial Intelligence" tools such as Large Language Models” [https://blog.codeberg.org/protecting-our-floss-commons-from-llms.html](https://blog.codeberg.org/protecting-our-floss-commons-from-llms.html)
[^fn11]: Applies to all code and data of projects and users on the Codeberg forge and associated services.
[^fn12]: project
